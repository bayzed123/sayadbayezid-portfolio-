Sidra Noor Fashion

A Vue 3 fashion storefront with eight admin screens behind it.

A Vue 3 fashion storefront with the admin dashboard its owner runs it from. The shop side has category pages, product pages, a cart and a checkout; the admin side has eight screens — dashboard, products, orders, customers, messages, staff, profile and a single-product editor.

Who it is for. Clothing shops that already sell on Facebook and want a real storefront without giving up the way they handle orders.

Core features

What it does

Eight admin screens

Dashboard, products, orders, customers, messages, staff, profile and a product editor — enough to run the shop, not a demo shell.

Shop side complete

Category pages, product pages, cart and checkout, all reachable and all working.

Staff, not just an owner

A staff screen, because a shop that grows stops being one person with one password.

Messages where the orders are

Customer messages sit in the same dashboard as the orders they are about.

Invented data, said out loud

Every product, order, customer and message is made up. The dashboard opens without a sign-in so you can check that for yourself.

Why choose this

What you get that a template does not give you

Every demo is the real build

Nothing here is a mockup or a design file. Each one is deployed, and you click through it the way a customer would. If a link is dead you will find it, which is the point.

You get the admin, not just the shop

Most storefront demos stop at the shop front. The part that decides whether a business can actually run on it is the dashboard behind it, so that is included and unlocked.

Invented data, never borrowed

Every product, order, customer and figure in these demos is generated. No real client's catalogue, orders or customers appear in any of them.

Rebrandable before it is rebuilt

Colours, type and logo are variables, not decisions baked into markup. The first change you ask for should not need a rewrite.

Built for Bangladeshi connections

Tested at phone width on a slow connection, because that is how most of the traffic arrives — not on a desk at 1440px.

One person, start to finish

The same person writes the front end, the API and the deploy pipeline. There is no handover gap for a bug to live in.
