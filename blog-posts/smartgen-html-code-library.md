## 🎨 1. Background Codes Library
Background tools dictate the foundational visual layers of your UI containers. These generators ensure your backgrounds scale properly across responsive devices.

* **[Background Color](https://www.smartgentools.com/html-code-library/background-codes/background-color/)**: Generates cross-browser compatible CSS for solid background colors. Essential for establishing base UI themes and fallback colors before heavy assets load.
* **[Background Image](https://www.smartgentools.com/html-code-library/background-codes/background-image/)**: Outputs the CSS required to embed images as container backgrounds. Perfect for hero sections and banners, ensuring proper scaling without breaking layout flow.
* **[Background Position](https://www.smartgentools.com/html-code-library/background-codes/background-position/)**: Provides precise coordinate control (`center`, `top left`, etc.) over background images. Critical for ensuring the focal point of an image isn't cropped out on mobile screens.
* **[Background Repeat](https://www.smartgentools.com/html-code-library/background-codes/background-repeat/)**: Controls CSS tiling behavior (`repeat-x`, `no-repeat`). Prevents small background patterns, gradients, or logos from rendering improperly across wide viewports.
* **[Fixed Background](https://www.smartgentools.com/html-code-library/background-codes/fixed-background/)**: Implements `background-attachment: fixed` to create smooth, modern parallax scrolling effects using pure CSS, avoiding the overhead of heavy JavaScript libraries.

## 🔣 2. Character Codes Library
HTML entities are required to safely render special characters without breaking HTML validation or URL parsing. This library provides safe encoding for all symbols.

* **[Greek Characters](https://www.smartgentools.com/html-code-library/character-codes/greek-characters/)**: A complete reference for HTML entities (e.g., `&alpha;`) used in mathematical, scientific, and academic web content, preventing rendering errors across different server encodings.
* **[Ampersand Code](https://www.smartgentools.com/html-code-library/character-codes/html-ampersand-code/)**: Provides the exact HTML entity (`&amp;`) needed to safely render ampersands in text, a common source of broken links and XML validation failures.
* **[Special Symbols](https://www.smartgentools.com/html-code-library/character-codes/html-symbols/)**: A searchable index of UI symbols (arrows, stars, checkmarks). Faster and lighter for web performance than loading an entire icon font library like FontAwesome for simple visual cues.
* **[Currency & Trademark](https://www.smartgentools.com/html-code-library/character-codes/html-trademark-code/)**: Ensures legal and financial symbols (©, ™, €) render uniformly across all operating systems, avoiding the dreaded "missing character box."
* **[Space Code](https://www.smartgentools.com/html-code-library/character-codes/html-space-code/)** & **[Tab Code](https://www.smartgentools.com/html-code-library/character-codes/html-tab-code/)**: Delivers non-breaking space (`&nbsp;`) and tab entities for precise inline text formatting when standard CSS padding or margins aren't practical.
