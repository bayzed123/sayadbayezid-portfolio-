# 📝 ব্লগ ম্যানেজমেন্ট গাইড (অটোমেটেড সিস্টেম)

আপনার পোর্টফোলিও সাইটে এখন একটি অটোমেটেড ব্লগ সিস্টেম আছে। আপনাকে আর কোনো JSON কোড লিখতে হবে না। আপনি শুধু আপনার HTML আর্টিকেলটি আপলোড করবেন এবং একটি কমান্ড চালাবেন।

---

## 🚀 নতুন ব্লগ যোগ করার ধাপসমূহ

### ধাপ ১: HTML ফাইল তৈরি ও আপলোড
আপনার ব্লগের HTML ফাইলটি `blog_uploads/` ফোল্ডারে রাখুন। 
*টিপস: ফাইলের নাম ছোট হাতের অক্ষরে এবং স্পেসের বদলে হাইফেন (-) ব্যবহার করুন (যেমন: `my-new-article.html`)।*

### ধাপ ২: অটোমেটিক কনভার্ট করা
আপনার কম্পিউটারের টার্মিনালে বা গিটহাব কমান্ড লাইনে নিচের কমান্ডটি লিখে এন্টার দিন:
```bash
python3 scripts/convert_blogs.py
```
**এটি যা করবে:**
- আপনার HTML ফাইল থেকে টাইটেল, কন্টেন্ট, ট্যাগ এবং FAQ খুঁজে নেবে।
- অটোমেটিক একটি JSON ফাইল তৈরি করবে `blogs/` ফোল্ডারে।
- `blogs/index.json` ফাইলটি আপডেট করবে যাতে মেইন পেজে ব্লগটি দেখা যায়।

### ধাপ ৩: গিটহাবে পুশ করা
সবশেষে পরিবর্তনগুলো আপনার গিটহাব রিপোজিটরিতে সেভ করার জন্য এই তিনটি কমান্ড দিন:
```bash
git add .
git commit -m "Add new blog post"
git push origin main
```

## 🛠 প্রয়োজনীয় কমান্ডসমূহ (একনজরে)

| কাজ | কমান্ড |
|-----|--------|
| ব্লগ কনভার্ট করা | `python3 scripts/convert_blogs.py` |
| সব ফাইল সিলেক্ট করা | `git add .` |
| সেভ করা | `git commit -m "আপনার মেসেজ"` |
| অনলাইনে পাঠানো | `git push origin main` |

## 💡 কিছু গুরুত্বপূর্ণ টিপস

1. **HTML ফরম্যাট:** আপনার HTML ফাইলে অবশ্যই একটি `<h1>` ট্যাগ থাকতে হবে (এটিই ব্লগের টাইটেল হবে)।
2. **SEO ট্যাগ:** HTML ফাইলের `<meta name="keywords" content="...">` অংশে যে ট্যাগগুলো দেবেন, সেগুলোই ব্লগের ট্যাগ হিসেবে সেভ হবে।
3. **FAQ:** আপনি যদি HTML-এ `accordion` ক্লাস ব্যবহার করে FAQ তৈরি করেন, তবে সেগুলোও অটোমেটিক ব্লগে যুক্ত হয়ে যাবে।
4. **রিলেটেড পোস্ট:** আপনি যখন একই ক্যাটাগরির বা একই ধরণের ট্যাগ ব্যবহার করবেন, তখন ব্লগের নিচে অটোমেটিক "Related Articles" দেখা যাবে।

## ❓ সমস্যা হলে কি করবেন?
যদি কমান্ড চালানোর পর কোনো ভুল দেখায়, তবে নিশ্চিত করুন যে আপনার কম্পিউটারে `BeautifulSoup` ইনস্টল করা আছে। না থাকলে এই কমান্ডটি দিন:
```bash
pip install beautifulsoup4
```

এখন থেকে আপনার ব্লগিং হোক আরও সহজ এবং দ্রুত! 🚀
