# Blog System Setup Guide

## Overview

Your portfolio now has a fully functional blog system with the following features:

- **Dynamic Blog Page** (`blog.html`) - Displays all blog posts from `blogs.json`
- **Individual Blog Posts** (`blog-post.html`) - Dynamic blog post pages with auto-generated URLs
- **Auto-generated Permalinks** - URLs are automatically generated from blog titles (slugified)
- **JSON-based Content Management** - Manage all blog content in `blogs.json`
- **SEO Optimized** - Each blog post has proper meta tags, Open Graph tags, and canonical URLs
- **Responsive Design** - Works perfectly on desktop, tablet, and mobile devices

## File Structure

```
/
├── blog.html                 # Main blog listing page
├── blog-post.html           # Individual blog post template
├── blogs.json               # Blog content database
├── blog/                    # Blog directory (for future use)
├── .htaccess               # URL rewriting configuration
└── index.html              # Updated with Blog navigation link
```

## How to Add New Blog Posts

### Step 1: Edit `blogs.json`

Open the `blogs.json` file and add a new blog object to the `blogs` array:

```json
{
  "blogs": [
    {
      "id": 1,
      "title": "Your Blog Post Title",
      "excerpt": "A short summary of your blog post (150-200 characters)",
      "content": "Full blog post content. Use paragraph breaks (\\n\\n) to separate paragraphs.",
      "category": "Web Development",
      "date": "2026-05-12",
      "author": "Sayad Md Bayezid Hosan",
      "image": "https://example.com/image.jpg",
      "tags": [
        "tag1",
        "tag2",
        "tag3"
      ],
      "faq": [
        {
          "question": "What is this about?",
          "answer": "This is the answer to the question."
        }
      ]
    }
  ]
}
```

### Step 2: Understanding Each Field

| Field | Required | Description |
|-------|----------|-------------|
| `id` | Yes | Unique identifier for the blog post |
| `title` | Yes | Blog post title (used to generate URL slug) |
| `excerpt` | Yes | Short summary displayed in blog listing |
| `content` | Yes | Full blog post content (use `\n\n` for paragraph breaks) |
| `category` | Yes | Blog post category (e.g., "Web Development", "Digital Marketing") |
| `date` | Yes | Publication date in YYYY-MM-DD format |
| `author` | No | Author name (defaults to "Sayad Md Bayezid Hosan") |
| `image` | No | Featured image URL |
| `tags` | No | Array of tags for the blog post |
| `faq` | No | Array of FAQ items with `question` and `answer` fields |

### Step 3: Auto-generated URL

The blog system automatically generates URLs from your blog title:

**Title:** "AI Video Generation Masterclass: Creating Cinematic Content from Text"  
**Generated URL:** `/blog/ai-video-generation-masterclass-creating-cinematic-content-from-text.html`

The URL is generated by:
1. Converting to lowercase
2. Removing special characters
3. Replacing spaces with hyphens
4. Removing duplicate hyphens

### Step 4: Commit and Push

After updating `blogs.json`, commit and push your changes:

```bash
git add blogs.json
git commit -m "Add new blog post: [Your Blog Title]"
git push origin main
```

## Troubleshooting

### Blog posts not showing up
1. Check that `blogs.json` is valid JSON (use a JSON validator)
2. Ensure the `blogs` array is properly formatted
3. Clear browser cache (Ctrl+F5 or Cmd+Shift+R)

### URLs not working
1. Ensure `.htaccess` is in the root directory
2. Check that your server has `mod_rewrite` enabled
3. Verify that `AllowOverride All` is set in Apache configuration

### Images not loading
1. Check that image URLs are correct and accessible
2. Use HTTPS URLs for better security
3. Ensure images are in a supported format (JPG, PNG, WebP)

## Best Practices

1. **Keep excerpts concise** - 150-200 characters work best
2. **Use descriptive titles** - They become part of the URL
3. **Add featured images** - Improves visual appeal and engagement
4. **Include tags** - Helps with content organization
5. **Use categories** - Makes content easier to navigate
6. **Add FAQ sections** - Improves SEO and user engagement
7. **Keep content updated** - Regularly publish new posts
